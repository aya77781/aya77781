### What I care about when I build

- **Data integrity over cleverness** — ACID transactions and database-level Row Level Security rather than filters bolted on in application code
- **Security at the right layer** — roles read from the database, never from client-manipulable tokens; service keys confined to the server
- **AI as a component, not a demo** — cached, streamed, and always with a fallback when the model is unavailable
- **Documentation that survives the project** — system-design blueprints, not just READMEs
